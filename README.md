# HIYUNZA Frontend Prototype

This is Phase 1: a responsive, interactive frontend preview based on the supplied HIYUNZA screen reference.

## Open
1. Extract `HIYUNZA_Frontend_Prototype.zip`.
2. Open `index.html` in Chrome, preferably on a phone or desktop browser.
3. Use the navigation to preview Home, Templates, Characters, Profile and Inbox.

## Included
- Responsive desktop sidebar and mobile bottom navigation
- HIYUNZA dark-green / neon-green / white visual direction
- Home creation-tool cards and project entry
- Searchable and filterable template gallery (sample/demo content)
- Character gallery and New Project preview modal
- Profile and Inbox preview
- Interactive navigation and dialogs

## Important status
This is a frontend prototype only. Authentication, database persistence, real AI image/video/voice generation, payments, token transactions, rewards, creator earnings, moderation and owner admin controls are NOT yet operational. They require backend implementation, database setup, secure API integrations, hosting and approved service credentials. Sample template metrics and profile statistics are illustrative demo data, not real platform analytics.

The supplied logo reference image is included in `assets/` for brand reference. The small temporary symbol in the prototype is a placeholder, not a replacement for the approved official logo artwork.
